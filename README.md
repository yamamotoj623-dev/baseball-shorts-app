# テキスト野球シミュ（MVP-1）

テキストベースの野球マネジメント・シミュレーション。
プレイヤーはGM／監督の目線で、オリジナル選手を育成・編成してペナントを進めていく——
その最初のコアである **「1試合の試合シミュレーション」** を実装したフェーズ（MVP-1）。

> 企画の全体像・収益モデル・ロードマップは [`docs/企画書.md`](docs/企画書.md) を参照。

## いま遊べること（MVP-1）

- 自動生成されたオリジナル2チームの対戦カードを表示（打順・能力値・先発投手）
- 「試合開始」で1試合を**イニング単位でテキスト実況**しながら進行
- ラインスコア／塁状況／アウトカウントがリアルタイム更新
- 再生速度の切り替え・最後まで早送り・別カードの再抽選

選手・チームはすべて自動生成のオリジナルで、実在の人物・球団とは無関係（権利リスク回避）。

## 技術構成

- **フロント**: Vite + React + TypeScript
- **シミュレーション**: `src/game/` に純粋なTSモジュールとして分離（UI非依存・テスト可能）
  - `types.ts` — 型定義
  - `rng.ts` — 再現可能な乱数（シード固定で同じ試合を再現）
  - `players.ts` — オリジナル選手・チームの自動生成
  - `simulation.ts` — 打席〜進塁〜得点の確率モデルと実況生成
- **UI**: `src/ui/`（スコアボード・ダイヤモンド・チームカード）

## セットアップ

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド
npm run test     # シミュレーションのテスト
```

## シミュレーションの考え方

1打席ごとに、投手能力（球速・制球・スタミナ）と打者能力（ミート・パワー・走力・守備）を
突き合わせて、四球／三振／凡打／単打〜本塁打を確率で決定する。投手は球数に応じて疲労し
終盤に球威が落ちる。約2000試合の集計で、合計得点・安打・本塁打・延長率が実際の野球に
近い分布になることを確認している。
